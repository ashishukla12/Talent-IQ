# Talent-IQ 🚀

A production-ready real-time technical interview platform designed for coding interviews, live collaboration, video communication, and candidate evaluation.

Talent-IQ enables interviewers and candidates to collaborate in real time through video calls, collaborative coding sessions, screen sharing, and chat messaging while leveraging modern authentication and event-driven backend architecture.

## ✨ Features

### 🔐 Authentication & Security

* Clerk Authentication
* Google Sign-In
* Secure Session Management
* Protected Routes
* User Synchronization

### 🎥 Interview Experience

* Real-Time Video Interviews
* Collaborative Code Editor
* Screen Sharing
* Interview Recording
* Camera & Microphone Controls
* Room Locking (2 Participant Limit)

### 💬 Real-Time Communication

* Live Chat Messaging
* Stream Chat Integration
* Instant Message Delivery
* Real-Time User Presence

### 📊 Platform Features

* Dashboard with Live Statistics
* Practice Problems
* Notifications & Alerts
* Candidate Interview Rooms
* Success & Error Feedback System

### ⚙️ Backend Features

* RESTful APIs
* Event-Driven Architecture
* Background Job Processing
* User Synchronization Workflows
* MongoDB Integration
